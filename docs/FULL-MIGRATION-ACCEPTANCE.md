# Full-migration acceptance

Topic note: this file originally recorded acceptance of the legacy Blocks → Runes migration. Its scope included the migration inventory, the five Code Mode tools, native JavaScript/TypeScript/Python execution, legacy argv compatibility, hash-bound overrides and adapters, original-source preservation, idempotent repeat migration, and focused test evidence.

Environment-specific inventories, machine paths, artifact hashes, process identifiers, and live installation records were removed for public release. Current migration behavior is documented in [FORMAT.md](FORMAT.md); security boundaries are in [SECURITY.md](SECURITY.md); installation and rollback guidance is in [INSTALLATION.md](INSTALLATION.md).
